Taller Ymaquina: Programación de Literatura Electrónica con IA

Hoy estaré ofreciendo un taller para lanzar el primer ciclo de Ymaquina, una iniciativa nueva de la Red Lit(e)Lat.

En este taller, les participantes aprenderán a cómo utilizar ChatGPT (u otro generador de código basado en IA de su elección) para generar código válido en HTML, CSS y JavaScript, y a usar un editor de código (mostraré Visual Studio Code) para crear una obra única de literatura electrónica o escritura digital. El taller busca capacitar a los participantes para aprovechar la inteligencia artificial en la producción de obras de literatura electrónica y escritura digital, al mismo tiempo que mejoran su destrezas de programación y lectura de código. Este conjunto de habilidades es fundamental para formar a nuestra comunidad, ya que reduce la barrera técnica para crear este tipo de obras.

Cómo usar la IA para crear una obra digital

La inteligencia artificial puede reducir significativamente las barreras de acceso para crear nuevos marcos de escritura digital, pero sí necesitas conocer algunos conceptos básicos de programación y tener una familiaridad general con las convenciones del lenguaje de programación que usarás y con las herramientas de depuración. Para los fines de este ejercicio, me enfocaré en HTML (incluyendo CSS y JavaScript).

Preparación

Antes de comenzar a usar indicaciones, piensa en qué tipo de estructura de escritura digital te gustaría crear. Aquí tienes un ejemplo de instrucciones para el sistema de IA que generará el código:

Crea una pagina html que hace lo siguiente: Una palabra (o frase o verso poético) aparece en el centro de la pantalla. Cuando el usuario la toca, cambia a otra palabra. Esto permite escribir una secuencia de palabras que puede completar una oración, contar una historia o desarrollar un poema. utiliza texto lorem ipsum para la secuencia de palabras.

Proceso

  1. Crea un nuevo documento con un editor de código (recomiendo Visual Studio Code) y asígnale un nombre sencillo en minúsculas, seguido del sufijo .html (por ejemplo, secuencia.html).
  2. Abre Chat GPT (o el sistema de IA que prefieras).
  3. Indícale a la IA que genere el código HTML que produzca el resultado deseado, comenzando con una indicación simple pero descriptiva.
  4. Copia y pega el código generado en tu documento.
  5. Guarda el documento y luego ábrelo (o recárgalo) en tu navegador para ver los resultados.
  6. Si no te gustan los resultados o quieres modificarlos, repite los pasos 3 al 5.
  7. Una vez que estés satisfecho con la estructura, modifica el código directamente en tu editor para que diga lo que tú quieras. Repite el paso 5 después de cada modificación.

Si el código deja de funcionar, tienes algunas opciones para depurarlo:

  • Verifica si el editor de código identifica el problema marcando el número de línea en rojo.
  • Abre las herramientas de desarrollo en tu navegador y busca los mensajes de error, los cuales te indicarán dónde están los problemas por número de línea y espacio.
  • Copia y pega tu código en el sistema de IA y pídele que lo repare. Describe el problema en tu indicación.
  • Usa la función de deshacer (Control/Command + Z) hasta que regreses a una versión anterior del documento que funcione.

Si el código se vuelve demasiado largo para que la IA lo lea, concéntrate en las secciones que deseas modificar, como el script, el estilo (CSS), el encabezado, etc. Asegúrate de copiar y pegar únicamente las secciones que deseas modificar.
