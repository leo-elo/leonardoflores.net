This tool juxtaposes a clock with a character and what is going through their mind at the time. Readers can modify the time to see the character's thought process at different times.

Programmed using Chat GPT 4.0 from January 20–March 16, 2024. Chat GPT provided the coding based on my prompts to create the framework. I modified the code and selected all the emoji for the work.
