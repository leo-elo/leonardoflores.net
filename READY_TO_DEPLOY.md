## Quick Deploy (3 Steps)

### Step 1: Create GitHub Repository

Go to: **https://github.com/new**

- Repository name: `leonardoflores-static`
- Description: `Static site for leonardoflores.net`
- **Public** repository
- **Do NOT** check "Initialize with README"
- Click "Create repository"

### Step 2: Push Your Code

Run these commands:

```bash
cd /Users/floresll/Desktop/github/leonardoflores-static

git remote add origin https://github.com/leo-elo/leonardoflores-static.git
git push -u origin main
git push -u origin gh-pages
```

### Step 3: Enable GitHub Pages

1. Go to: **https://github.com/leo-elo/leonardoflores-static/settings/pages**
2. Under "Source":
   - Branch: **gh-pages**
   - Folder: **/ (root)**
3. Click **Save**
