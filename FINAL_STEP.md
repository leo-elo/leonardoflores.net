# Final Step - Enable GitHub Pages 🚀

Your code is successfully pushed to GitHub! Now enable GitHub Pages to make it live.

## Go Here:
**https://github.com/leo-elo/leonardoflores.net/settings/pages**

## Configure These Settings:

1. **Source**
   - Branch: **gh-pages**
   - Folder: **/ (root)**
   - Click **Save**

2. **Custom domain** (will appear after saving)
   - Enter: **leonardoflores.net**
   - Click **Save**
   - Check ✅ **Enforce HTTPS**

## Your Site URLs

After enabling (takes 1-2 minutes):

**GitHub Pages:**
- https://leo-elo.github.io/leonardoflores.net/

**Custom Domain** (after DNS setup):
- https://leonardoflores.net/
